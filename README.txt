# Diet King Demo v2

A polished standalone static demo recreated from the Diet King design direction and supplied menu/pricing material.

## Included
- Responsive HTML/CSS/JS website
- Local hero MP4
- Supplied Diet King product imagery
- Menu category filters
- Consistent nutrition cards
- Clear placeholder when nutrition data was not supplied (no fabricated values)
- Redesigned, tabbed plans & pricing section
- WhatsApp order flow
- Terms & Conditions section
- No Bolt dependency

## Run locally
Open `index.html` in a modern browser.

If the browser blocks local video or other local features, run a simple local server from this folder:

`python -m http.server 8000`

Then visit `http://localhost:8000`.
